## 七、TTM股息算法修正

### v1.1b 正确定义

```python
TTM股息 = Σ(除权除息日在 [as_of_date - 1 calendar year, as_of_date] 内的已实施分红派息)
每股现金分红 = 派息 ÷ 10  # 每10股→每股（税前）
```

**不使用365天**（闰年误差），使用 `as_of_date.replace(year=as_of_date.year-1)`。

### 送转折算

当前样本（格力、茅台、神华、招行）近1年均无送转事件，每股分红 = 派息 ÷ 10 直接成立。

**若遇到送转/拆合股，公式为：**

```
调整后每股分红 = 原每股分红 ÷ 此后累计送转/拆股倍数
```

其中累计倍数为后续所有送转事件的 `(1 + 送股/10 + 转增/10)` 累积积。**不得使用价格复权因子**（价格复权含现金分红调整，会双重计算）。
